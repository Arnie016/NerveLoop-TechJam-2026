# Devpost gallery v2

Four 1800×1200 judge-facing cards explain the project in order:

1. the product promise;
2. the host-owned multi-role control system;
3. the deterministic measured result; and
4. the explicit proof boundary.

The background plate was generated with the built-in OpenAI image-generation
tool in generation mode, then copied into this project. Prompt intent: a dark
graphite, restrained cyan/mint flow-field shader with calm negative space and no
text, logos, interface elements or recognizable branding. Exact typography,
diagrams and claims were authored as deterministic SVG and rendered locally to
PNG. The SVG files remain the editable source of truth.

The cards make no claim of TikTok access, OS-level sandboxing, provider-backed
execution, production-scale performance or independent security validation.
